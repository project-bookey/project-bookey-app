# Bookey postcard envelopes

Generated with the built-in image generation tool. Transparent PNG assets; originals remain in Codex generated_images. Used by PostcardEnvelope with contain sizing, theme selection, and opened/closed state. No message content is included.

The app now references optimized WebP copies in `../optimized/postcard-envelopes`. These PNGs are retained as source masters. Regenerate the optimized copies with `node scripts/optimize-ui-images.mjs` (requires `sips` and `cwebp`).
