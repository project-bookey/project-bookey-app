# Bookey 출시 QA 체크리스트

각 항목은 iOS와 Android 실기기에서 각각 수행한다. 실패 시 기기·OS·앱 빌드·시각·화면 녹화와 API 오류 코드를 남긴다.

## 계정

- [ ] 신규 이메일로 인증 코드 요청 → 올바른 코드로 가입된다.
- [ ] 만료·오입력 코드는 가입되지 않으며 재발급할 수 있다.
- [ ] 이용약관과 개인정보 문서를 각각 끝까지 읽기 전에는 동의할 수 없다.
- [ ] 두 필수 문서 동의 전에는 가입 버튼이 비활성화된다.
- [ ] 로그아웃 후 토큰이 제거되고 보호 화면에 접근할 수 없다.
- [ ] 계정 삭제 후 이전 자격 증명으로 로그인할 수 없다.

## 푸시·딥링크

- [ ] 최초 권한 허용 후 서버에 Expo Push Token이 등록된다.
- [ ] 채팅·찌르기·독서 재촉 알림이 잠금·백그라운드 상태에서 도착한다.
- [ ] 알림을 누르면 대상 화면으로 이동하고 읽음 처리된다.
- [ ] 로그아웃 상태에서 알림을 눌러도 보호 화면이 노출되지 않는다.
- [ ] 앱 삭제 등으로 폐기된 토큰이 Receipt 확인 후 비활성화된다.

## 독서·커뮤니티

- [ ] 책 검색, 서재 추가, 진행률 변경, 완독 처리가 반영된다.
- [ ] 타이머 중 백그라운드 전환 후 시간이 정확히 복원된다.
- [ ] 독후감·밑줄·댓글 작성 및 이미지 업로드가 정상 동작한다.
- [ ] 신고·삭제·차단된 콘텐츠가 목록과 상세에서 일관되게 사라진다.
- [ ] 네트워크 단절 중 작성 실패가 명확히 안내되고 중복 등록되지 않는다.

## 채팅·출석·지갑

- [ ] 채팅 전송 직후 메시지가 한 번만 보인다.
- [ ] 앱을 백그라운드에서 복귀하면 새 메시지가 즉시 동기화된다.
- [ ] 같은 날 출석 버튼을 반복해도 보상이 중복 지급되지 않는다.
- [ ] 7·14·21·28번째 출석에 엽서·우표가 정확히 교차 지급된다.
- [ ] 월이 바뀌면 월 출석 횟수가 새로 계산된다.
- [ ] 결제 완료·취소·앱 강제 종료 후 지갑과 구독 상태가 서버와 일치한다.

## 화면·장애 대응

- [ ] 작은 화면, 큰 글자, 다크 모드에서 주요 버튼과 문구가 잘리지 않는다.
- [ ] VoiceOver/TalkBack으로 가입과 핵심 탐색이 가능하다.
- [ ] 서버 4xx·5xx·타임아웃에서 무한 로딩 대신 복구 가능한 안내가 나온다.
- [ ] 앱 강제 종료·재실행 후 로그인과 작성 중 데이터 상태가 예측 가능하다.
