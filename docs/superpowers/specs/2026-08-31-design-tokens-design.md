# bookey OTT 디자인 토큰 체계 — 설계 문서

2026-08-31 · 브레인스토밍 세션에서 사용자와 함께 결정

## 목표

bookey를 "책 OTT" — 넷플릭스·디즈니+ 같은 콘텐츠 플랫폼의 문법으로 다시 디자인한다.
화면 작업에 앞서 디자인 토큰을 먼저 확정한다. 기존 "필사본·타자기" 테마(밝은 종이 배경,
세리프 본문, 타자기 등폭)는 전면 교체한다.

## 결정 요약

| 항목 | 결정 | 근거 |
|---|---|---|
| 컬러 스킴 | 다크 기본 + 라이트 지원 | 시스템 설정 추종. 밝은 화면을 선호하는 독서 사용자 배려 |
| 다크 기조 | 뉴트럴 차콜 (#141414 계열) | 무채색이라 색이 제각각인 책 표지가 가장 잘 돋보임 |
| 악센트 | 틸 민트 (다크 #1FC7A8 / 라이트 #0E9F85) | 다크 위 가독성·현대적 인상. 시각 비교로 선택 |
| 타이포 | 시스템 폰트 | 번들 비용 0. 위계는 크기·웨이트 토큰으로만 표현 |
| 형태 | 샤프 (2–4px) | 넷플릭스 타일에 가까운 밀도 높은 시네마틱 인상 |
| 코드 구조 | 순수 TS 시맨틱 토큰 + `useTheme()` 훅 | 의존성 0, 실시간 모드 전환, 미니멀 스택과 일치 |

## 컬러 토큰

하나의 시맨틱 계약(`ColorTokens` 타입)을 다크/라이트 두 벌 값으로 채운다.
두 팔레트 모두 같은 타입을 만족해야 하므로, 한쪽에만 키를 추가하면 `npm run typecheck`가 실패한다.

| 토큰 | 다크 (기본) | 라이트 | 용도 |
|---|---|---|---|
| `bg` | `#141414` | `#FAFAFA` | 화면 배경 |
| `surface` | `#1F1F1F` | `#FFFFFF` | 카드·행 |
| `surfaceRaised` | `#2A2A2A` | `#F0F0F0` | 시트·모달·눌림 상태 |
| `text` | `#F5F5F5` | `#171717` | 본문·제목 |
| `textMuted` | `#A6A6A6` | `#595959` | 보조 텍스트 |
| `textFaint` | `#737373` | `#8C8C8C` | 플레이스홀더·비활성 |
| `line` | `#333333` | `#E3E3E3` | 헤어라인·트랙 |
| `lineStrong` | `#4D4D4D` | `#C7C7C7` | 아웃라인 버튼 테두리 |
| `accent` | `#1FC7A8` | `#0E9F85` | CTA·진행 바·링크·긍정 상태 |
| `onAccent` | `#0E1512` | `#FFFFFF` | 악센트 배경 위 텍스트 |
| `accentSoft` | `#12352E` | `#DFF7F1` | 악센트 틴트 배경 (배지 등) |
| `warn` | `#F0B429` | `#8A5A12` | 경고 텍스트·아이콘 |
| `warnSoft` | `#38290F` | `#FDF0D5` | 경고 틴트 배경 |
| `danger` | `#FF6B60` | `#B3362B` | 위험 텍스트·아이콘 |
| `dangerSoft` | `#3A1714` | `#FBE4E1` | 위험 틴트 배경 |
| `scrimDim` | `rgba(0,0,0,0.55)` | `rgba(0,0,0,0.45)` | 전면 딤 (모달 뒤) |

핵심 규칙:

- **악센트는 틸 하나.** "순항" 같은 긍정 상태색도 악센트가 겸한다. 별도 success 색을 두지 않는다
  (틸과 초록의 충돌 방지, 색 수 최소화).
- **다크의 높이 표현은 밝기.** 그림자 대신 `bg → surface → surfaceRaised` 밝기 단계로 위계를 만든다.
  라이트 모드에서만 카드에 아주 옅은 그림자 1종을 쓴다.
- **포스터 위 텍스트는 스크림 위에.** 히어로·표지 위 글자는 검정 그라데이션(하단→투명)을 깔고 올린다.
  팔레트에 `scrimStops: ['transparent', 'rgba(0,0,0,0.85)']` (색 스톱 배열, 두 모드 동일)로만
  정의하고, 렌더링은 해당 화면을 만들 때 `expo-linear-gradient`를 추가해서 처리한다
  (토큰 단계에서는 의존성을 추가하지 않는다).

## 브랜드 자산

- **로고**: `assets/logo.png` — "B" 레터마크 + 북마크. 북마크는 UI 악센트와 같은 틸(`#1FC7A8`)로
  리컬러해 브랜드와 UI를 한 색으로 통일했다 (원본 북마크는 그린 `#1CB63E`).
- **로고 네이비(`#222A3B`)** 는 로고 전용 색이다. 팔레트 토큰으로 승격하지 않으며,
  뉴트럴 차콜 배경 위에 그대로 올린다.
- 앱 아이콘·스플래시(`assets/icon.png` 등) 교체는 화면 리디자인과 함께 후속 작업으로 처리한다.

## 타이포그래피

폰트는 시스템 기본(iOS: SF/Apple SD 산돌고딕, Android: Roboto/Noto Sans). `fontFamily`를 지정하지
않는 것으로 구현한다. 위계는 크기·웨이트·자간으로만 만든다.

| 토큰 | 크기/웨이트 | 용도 |
|---|---|---|
| `display` | 28 / 800 / 자간 -0.5 | 히어로 책 제목 |
| `title` | 22 / 700 | 화면 제목 |
| `section` | 17 / 700 | 행(캐러셀) 머리글 |
| `body` | 15 / 400 / 행간 22 | 본문 |
| `bodyStrong` | 15 / 600 | 강조 본문 |
| `label` | 13 / 600 | 버튼·탭·칩 |
| `caption` | 12 / 400 | 메타 정보 |
| `overline` | 11 / 700 / 자간 +1.5 | 아이브로우 (주로 악센트 색) — 기존 ❧ 장식의 대체 |

## 형태 · 간격 · 모션

**반경** — 기존 키를 유지하고 값만 샤프하게 재조정한다 (기존 화면 호환):

| 토큰 | 값 | 용도 |
|---|---|---|
| `radius.none` | 0 | |
| `radius.sm` | 2 | 책 표지 |
| `radius.md` | 4 | 카드·버튼·칩·입력 |
| `radius.lg` | 8 | 시트·모달 |
| `radius.pill` | 999 | 아바타·토글 손잡이만 (버튼에 쓰지 않는다) |

**간격** — 기존 스케일 그대로: `xs 4 · sm 8 · md 12 · lg 16 · xl 24 · xxl 36`.
화면 좌우 여백 `lg`, 섹션 사이 `xl`.

**모션** — `fast 150ms`(터치 피드백) · `base 250ms`(화면 전환·페이드) · `slow 400ms`(히어로·시트).
이징은 표준 ease-out.

**엘리베이션** — 다크: 없음(밝기 단계로 대체). 라이트: 카드 전용 그림자 1종
(`opacity 0.06, radius 10, offset 0/2`). 모드별 값이므로 팔레트와 함께 `cardShadow`로 제공한다.

## 코드 구조

```
src/theme/
├─ tokens.ts     모드 무관 — spacing, radius, type, motion, layout
├─ palette.ts    ColorTokens 타입 + darkColors / lightColors + cardShadow
├─ useTheme.ts   useColorScheme() → { mode, colors, cardShadow }
└─ index.ts      재수출 (+ 임시 호환 레이어)
```

- **`useTheme()`** — RN `useColorScheme()`을 감싼다. 값이 `null`이면 다크(기본) 폴백.
  앱 내 수동 테마 전환이 필요해지면 훅 내부만 바꾼다 — 호출부는 그대로.
- **화면 패턴** — 레이아웃은 정적 `StyleSheet.create`, 색은 `const { colors } = useTheme()`로
  받아 인라인으로 얹는다. 스타일 팩토리·라이브러리 없음.
- **도메인 스타일 맵** — `lagStyle`·`paceStyle`은 팔레트를 따라가야 하므로
  `getLagStyle(colors)`·`getPaceStyle(colors)` 함수로 바꾼다. 순수 텍스트인 `statusLabel`은 정적 유지.
- **StatusBar** — 루트 레이아웃에서 `"dark"` 고정을 모드 추종으로 변경 (다크 모드 → `"light"`).
  `app.json`의 `userInterfaceStyle: "automatic"`은 이미 설정돼 있다.

## 마이그레이션 · 호환성

이번 작업의 스코프는 **토큰 체계 구축까지**다. 13개 화면 + `ui.tsx`의 OTT 리디자인은 별도
후속 작업이며, 화면 단위로 새 토큰에 갈아탄다.

토큰 도입 시점에 앱이 깨지지 않도록:

- 기존 화면이 참조하는 색 키(`surfaceAlt`, `ink`, `trackEmpty`)와 export(`fonts`, `mono`,
  `ornament`, `hairline`, `elevation`, 정적 `lagStyle`·`paceStyle`)는 **임시 호환 레이어**로 유지한다
  — 새 다크 값으로 매핑된 별칭이며 `@deprecated` 표시. 화면 리디자인이 끝나면 제거한다.
- 즉 토큰 교체 직후의 기존 화면들은 "레이아웃은 그대로, 색만 다크"인 과도기 상태로 동작한다.
  이는 의도된 중간 단계다.

## 검증

- `npm run typecheck` — 팔레트 계약(두 팔레트의 키 일치)과 호환 레이어가 깨지지 않는지 확인.
- `npm run web`으로 다크/라이트 각각 육안 확인 (브라우저 개발자 도구의 `prefers-color-scheme`
  에뮬레이션 사용).
- 테스트 스위트는 이 저장소에 없으므로 추가하지 않는다.
