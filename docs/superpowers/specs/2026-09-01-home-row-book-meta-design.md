# 홈 추천·인기 행 — 작가 표시 설계

2026-09-01 · 브레인스토밍 결과

## 배경

홈의 "추천"·"인기" 행은 표지와 제목 한 줄만 보여줘서, 책을 고를 때 작가를 확인하려면 상세 화면까지 들어가야 한다. 처음 요청은 "커서를 올리면 작가·제목·년도·출판사 표시"였으나, hover가 웹에만 존재하는 점과 시각 비교를 거쳐 아래로 확정했다.

## 확정된 결정

1. **hover 대신 항상 표시** — 모든 기기(iOS/Android/웹)에서 동일하게 동작한다.
2. **정보량은 작가까지** — 표지 아래 제목 + 작가 2줄. 출판사·출간년도는 홈에서 판단 재료가 아니므로 상세 화면에 맡긴다.
3. **레이아웃은 표지 아래 메타 스택** — 오버레이·와이드 카드 안을 시각 비교로 검토했으나, 2줄 정보에는 기존 구조 확장이 가장 단순하고 깔끔하다.

## 변경 내용

### `src/components/home/BookRow.tsx`

- `RowBook` 타입에 `author?: string` 추가.
- 표지 아래 제목 줄을 강조한다: `typeScale.caption` + `sans.semiBold` + `colors.text`. 모든 행에 공통 적용해 행끼리 위계가 어긋나지 않게 한다.
- `author`가 있으면 제목 아래 작가 줄을 렌더한다: `typeScale.caption`, `colors.textMuted`, `numberOfLines={1}` 말줄임. 없으면 줄 자체를 그리지 않는다.

### `app/home.tsx`

- "추천" 매핑에 `author: b.author`, "인기" 매핑에 `author: p.book.author` 추가.
- 서버 `BookSummary`에 `author` 필드가 이미 있으므로 API·타입 재생성은 불필요하다.

## 범위 밖

- "읽는 중"·"읽고 싶은" 행과 검색 화면: `author`를 넘기지 않으므로 기존 표시 유지 (제목 강조만 공통 적용).
- 출판사·출간년도 표시, 책 상세 화면 변경 없음.

## 검증

- `npm run typecheck`
- `npm run web`으로 홈에서 추천·인기 행에 작가 줄이 보이는지, 다른 행은 제목만 유지되는지 확인.
