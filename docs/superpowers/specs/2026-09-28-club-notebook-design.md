- 약속(meeting)과는 독립. 연결은 후속.

## 문서 스키마 (앱 소유 — `noteDoc.ts`)

서버는 문서를 jsonb 로 불투명하게 저장하고 요소 수(300)·크기(512KB)만 검사한다. 그래서 CLAUDE.md "서버 응답 필드를 손으로 쓰지 않는다" 규칙의 유일한 예외가 이 파일이다. 생성 타입은 `{ [key: string]: unknown }` 이고 `parseDoc` 이 경계에서 좁힌다(모르는 요소는 버리고 절대 throw 하지 않는다).

- 논리 캔버스 1000×1333(3:4). 화면엔 `scale = 페이지 px 폭 / 1000`. `x·y` 는 회전 전 박스 좌상단, `rot` 는 도.
- 높이는 저장하지 않는다(텍스트·말풍선은 레이아웃이 정함). 사진만 `h`(프레임 바깥 크기, 안쪽 여백 6·아래 폴라로이드 여백 18).
- 색은 토큰 이름(`PenColor`: ink·accent·red·blue·yellow·muted)으로 저장하고 렌더 시점 테마에서 푼다 — 다크·라이트 어디서 봐도 보인다. 파랑은 팔레트에 없어 `penBlue` 를 두 팔레트에 추가했다.
- 잉크는 항상 요소 위에 그린다(사진에 동그라미, 글에 밑줄). 같은 (색,굵기) 획은 `Path` 하나로 이어 붙인다.

## 모임 탭 · 모두의 노트 피드 (2026-09-28 저녁 추가)

사용자 요청 "모임 메뉴를 쉽게 알아보게 · 탭 형식 · 노트는 인스타처럼 모두의 노트를".
- 모임 화면 헤더 아래에 `ClubTabs`(홈 · 채팅 · 약속 · 토론 · 노트)를 둔다. 활성 = 잉크 글자 + 2px 민트 표식(구역 네비 규칙). ☰ 메뉴는 없앴고 호스트 전용 '모임 관리'는 헤더 톱니로. 홈으로는 `navigate`, 하위 화면끼리는 `replace` 라 뒤로 가기는 항상 모임 홈으로 떨어진다.
- 노트 탭은 **모두의 노트 피드**(`app/club/[id]/notebook/index.tsx`): 만든 사람 줄 → 페이지 미리보기(3:4 읽기 전용) → 제목 카드를 최근 수정순으로 쌓는다. 카드를 누르면 편집 화면(`notebook/[pageId].tsx`)이 그 페이지로 열리고, 보기 모드 스와이프로 이웃 페이지를 오간다. 편집 권한은 그대로 멤버 누구나.

## 편집 모델

- 도구 = 모드: 보기(`hand`) · 선택 · 펜 · 지우개. 삽입 4종(텍스트·스티커·사진·말풍선)은 시트를 여는 동작이고 넣은 뒤 선택 모드로 간다.
- 페이저(`FlatList horizontal pagingEnabled`)는 보기 모드에서만 스크롤된다 — 제스처 중재 대신 모드로 충돌을 없앴다(웹 마우스에서도 같은 동작).
- 선택: 탭 = 선택, 더블탭 = 편집(텍스트·말풍선), 드래그·핀치·회전 + **우하단 모서리 핸들**(중심 벡터 변화로 크기·각도 동시에 — 웹 마우스는 핀치를 못 내므로 필수). 진행 중엔 문서를 건드리지 않고 `preview` 델타만 얹고, 손을 떼면 커밋한다(좌상단 고정 확대).
- 펜: 페이지 위 Pan 하나가 JS 스레드(`runOnJS`)에서 점을 모아 rAF 로 라이브 획을 갱신, 떼면 RDP(ε 1) 로 줄여 문서에 넣는다(획 800점·페이지 400획 상한). 지우개는 획 통째 삭제, 드래그 한 번 = 되돌리기 1건.
- 되돌리기 30단계. 같은 `batch` 키의 연속 apply(타이핑 세션, 지우개 드래그)는 한 건.
- 자동 저장: 마지막 변경 1.5초 뒤, 화면을 떠날 때·앱 배경·페이지 넘기기 전엔 즉시. 응답은 요약만(문서 에코 없음).
- 사진: 앨범 1장 → `prepareImage`(1600px JPEG) → `POST …/notebook/images`(모임 단위) → 응답 id·url 을 photo 요소에 넣어 저장하면 서버가 그 페이지에 붙인다. 업로드 중엔 문서 밖 자리표시자. 서버 저장소가 꺼져 있으면(503) 세션 동안 사진 도구를 잠근다.
- PNG: `sharePng`(`src/lib/sharePng.ts`, 주간 카드와 공용) 로 1080×1440. 선택 프레임·업로드 중 사진은 캡처 뷰의 형제라 찍히지 않는다.
